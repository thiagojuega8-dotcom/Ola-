# Hilo Rojo

Prototipo de una aplicación para parejas, creado con React, Vite, Tailwind CSS y Lucide.

## Ejecutar en Codespaces

1. Instala las dependencias:

   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo, exponiéndolo para que Codespaces pueda abrirlo:

   ```bash
   npm run dev -- --host 0.0.0.0
   ```

3. Abre en el navegador el puerto que Vite muestre en la terminal (normalmente el `5173`).

## Comandos disponibles

- `npm run dev`: inicia el servidor de desarrollo.
- `npm run build`: genera el paquete de producción en `dist/`.
- `npm run preview`: sirve localmente el paquete de producción.

La aplicación es actualmente un prototipo de interfaz: no incluye backend, autenticación, sincronización entre parejas ni persistencia de datos.
